# 研究方法與限制

本專案研究台灣ETF動態曝險能否在成本及風險約束下改善持有0050的結果。工程驗收與投資績效驗證分開：測試通過不代表策略有收益，資料表可解析也不代表當時可用或可以成交。

## 已做的方法

- 固定配置、估值／盈餘、波動調整、現金保留、退出及回場機制的逐項比較。
- 同期間、同本金／入金、相同成本的基準對照；紀錄股息支付、分割、整數單位、結算與延後成交。
- 將真實ETF資料與較早危機的合成資料分開；NAV（基金每單位資產淨值）假設成交不當作市場成交回測。
- 保存來源指紋、原文取得時間與研究設定，拒絕同資料／規則換目錄重跑；重疊窗口不稱獨立勝率。

例如ETF分割後單價降低、持有單位增加，投資價值不因此憑空損失。若只拿原始單價計算報酬，可能誤判崩跌、誤觸退出；來源與公司行動驗收要先於績效比較。

## 目前結論

尚無候選證明能同時達成高於0050的報酬、波動與最大回撤不高於0050，以及既定損失約束。部分加權正二固定配置在已見歷史的淨值情境有較高報酬，也有較高風險；既有波動動態規則沒有提供所需優勢。不因結果不理想持續掃舊參數，也不包裝成可實盤獲利工具。
